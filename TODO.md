- Replace the loopback bridge with Chrome Native Messaging. Since 1.15.0 the handshake is a mutual challenge-response in which the token never crosses the socket, so a squatter on 127.0.0.1:8765 learns nothing, and the token file is restricted to the current user. The remaining gap is that the secret is still a file the user account can read, so any process running as the same user can read it and impersonate either side. With Native Messaging Chrome starts the server itself over stdio, no port is listened on at all, and the trust boundary becomes the extension ID Chrome enforces instead of a file on disk. Pipe framing and the native-vs-fallback guard are specced in `docs/native-messaging-design.md`.
